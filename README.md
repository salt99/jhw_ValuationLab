## 네 도구

1. **능력범위 체크리스트** — 거장 검증 6개 항목(린치·버핏·멍거·그레이엄·피셔·포퍼/소로스).
2. **기업 프리미엄 체크리스트** — 11개 프리미엄 요소 + 3×3 매트릭스.
3. **밸류에이션 4-모드 분석기** — PBR·ROE·N·r 중 3개로 나머지 1개 역산.
4. **켈리 · 분할매수 플래너** — 종목별 상단·Base·하단 목표가와 시나리오 확률로 **풀 켈리** 값을 구하고, 그 값을 상대 매력도로 삼아 배분. **개별 종목 상한 30%**, 초과분은 다른 종목이 아니라 **채권**으로. 목표 포트폴리오를 **8분기 분할매수** 매매일지로 실행합니다.

## 주의

- 모든 데이터는 `localStorage`(본인 기기에만 저장, 서버 전송 없음). 네 도구는 서로 다른 저장 키를 써서 충돌하지 않습니다.
- 켈리 배분기는 확률·목표가가 정확하다고 가정합니다. 실제로는 추정치이며, 종목 간 상관관계도 보지 않습니다. 개별 상한 30%는 켈리를 정확하게 만드는 장치가 아니라 켈리가 못 보는 것(왼쪽 꼬리·상관관계)을 상쇄하는 장치입니다. 매매 지시가 아닌 사고 보조 도구입니다.
