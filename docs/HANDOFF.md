## 알아야 할 것

- **자체 검사를 터미널에서 돌리는 법**이 문서에 있다 —
  `browser-checklist-rejection-ledger.md` 의 `<details>` "화면을 볼 수 없을 때".
  `open _selfcheck.html` 은 창만 띄우고 결과가 안 돌아온다. Chrome 151 은
  `--dump-dom` 후에도 **종료하지 않으므로** 백그라운드로 돌리고 죽여야 한다.
  `--virtual-time-budget` 을 붙이면 더 오래 매달리니 쓰지 않는다.
- 로컬 http 오리진은 localStorage 가 비어 있어 `저장 포맷` 1건이 SKIP 된다. 정상이다.
- `test_pipeline.js` 는 `PIPELINE PURE` 블록을 정규식으로 추출한다. 새 순수 함수를
  넣을 때는 **그 블록 안에** 넣고 `test_pipeline.js:7-10` 의 export 목록에도 더해야 한다.
- 카드에 새 버튼을 추가하면 `bindPipeline()` 에 핸들러를 물려야 한다. 마크업만 넣으면
  눌러도 아무 일이 없고 **에러도 안 난다** — 조용히 실패한다.

## 손대지 말 것

- **`stripReviewFields(c, editing)` 의 `editing` 가드.** 기각 기록을 *수정*할 때
  지우면 안 된다. 지금은 수정 시점에 그 필드들이 없지만, 가드를 빼면 나중에
  검토 필드를 되살릴 때 수정만으로 데이터가 날아간다. 테스트 2건이 이걸 지킨다.
- **체크박스 토글 핸들러가 `render()` 를 안 부르는 것.** 목록을 다시 그리면
  모바일에서 스크롤이 튄다. 체크박스는 진짜 `<input type=checkbox>` 라 표시는
  브라우저가 알아서 한다.
- **`origin` 을 필수 입력으로 만들지 말 것.** 종목을 발견한 순간 빠르게 적어두는
  가벼움이 파이프라인의 진입 마찰을 낮춘다. 사용자가 명시적으로 그렇게 판단했다.
- **기존 보유 종목에 논지를 소급 입력하게 만들지 말 것.** 이미 주가를 아는 상태의
  사후 서술이다 — 검토 시작일을 안 받는 것과 같은 이유다.
- **청산 종목의 매매 이력 모달은 읽기 전용이 의도다**(§7-D18). 자동 검사의
  `읽기 전용 — 편집 요소 없음` 항목이 이걸 지킨다.
- `todayStr()` 의 UTC 기준 (PRD §8).
